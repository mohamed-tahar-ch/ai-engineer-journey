# AI Engineer Journey

Parcours structuré et documenté de ma transition vers le métier d'**AI Engineer**, en partant d'une base en développement (Python, C, Java) et d'un Master 2 en IA & IoT (Machine Learning, systèmes multi-agents, analyse de données, data mining).

Ce dépôt sert de journal de bord technique : chaque semaine correspond à un dossier avec du code réel, testé, et documenté — pas des tutoriels recopiés.

## 🎯 Objectif

Devenir opérationnel sur les compétences réellement demandées par les offres "AI Engineer" en 2026 : construction d'applications LLM en production (RAG, agents, MCP, tool calling), pas de la recherche en deep learning.
